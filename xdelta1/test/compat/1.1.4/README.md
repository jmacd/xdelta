# Xdelta 1.1.4 compatibility fixture

`change.xdelta` was generated by the pristine Xdelta 1.1.4 source restored in
git commit `803cbd3`. That source came from `xdelta-1.1.4.tar.gz`, whose SHA-256
digest is recorded in `HISTORICAL.md`.

The SHA-256 digest of `change.xdelta` is:

```text
a80817bb8c0d79a5680ca92ef14ee1862c17ab840d7f081e52eca00480f2bb28
```

The historical source was built in an `amd64` Debian container against GLib
1.2.10 and zlib. No Xdelta source files were modified. GLib 1.2.10 required
GNU89 inline semantics and a compiler-compatibility change to its diagnostic
use of `G_GNUC_PRETTY_FUNCTION`; neither change affects Xdelta.

The fixture establishes one narrow guarantee: current Xdelta can identify and
apply this patch produced by Xdelta 1.1.4. It does not establish compatibility
with every option or earlier Xdelta 1.0 formats.
