Release 3.0j (<a href="http://code.google.com/p/xdelta/downloads/list">download</a>)<br /><br />The self-test (run by <code>xdelta3 test</code>) now passes. There had been a regression related to external-compression, and several tests had to be disabled on Windows. Also fixes VCDIFF info commands on Windows (e.g., <code>xdelta3 printdelta <em>input</em></code>) and memory errors in the Python module.<br /><br />Thanks for your continued feedback (file a new <a href="http://code.google.com/p/xdelta/issues/entry">issue</a>). A user reports that <code>xdelta3.exe</code> should not depend on the C++ 8.0 Runtime. I agree&mdash;this is written in C. The source release includes a <code>.vcproj</code> file, in case you'd like to try for yourself.
