<a href="http://dot.kde.org/1067849710/1068041820">KDE.org</a> asked how to use xdelta3. Like gzip with the additional <tt>-s SOURCE</tt>. Like gzip, <tt>-d</tt> means to decompress, and the default is to compress. For output, <tt>-c</tt> and <tt>-f</tt> flags behave likewise. Unlike gzip, xdelta3 defaults to <tt>stdout</tt> (instead of having an automatic extension). Without <tt>-s SOURCE</tt>, xdelta3 behaves like gzip for <tt>stdin</tt>/<tt>stdout</tt> purposes. <a href="http://code.google.com/p/xdelta/wiki/CommandLineSyntax">See also</a>.<br /><br />Compress examples:<br /><br /><tt>xdelta3 -s SOURCE TARGET &gt; OUT</tt><br /><tt>xdelta3 -s SOURCE TARGET OUT</tt><br /><tt>xdelta3 -s SOURCE &lt; TARGET &gt; OUT</tt><br /><br />Decompress examples:<br /><br /><tt>xdelta3 -d -s SOURCE OUT &gt; TARGET</tt><br /><tt>xdelta3 -d -s SOURCE OUT TARGET</tt><br /><tt>xdelta3 -d -s SOURCE &lt; OUT &gt; TARGET</tt>
