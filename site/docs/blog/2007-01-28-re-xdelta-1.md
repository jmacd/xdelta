Re: Xdelta 1.1.4<br /><br />An especially grateful user wrote me to say thanks for the open-source software:<ul>Firstly, Xdelta is an impressive piece of software, and I appreciate you writing it.  I've done some tests and found it to be orders of magnitude faster than <a href="http://www.pocketsoft.com/rtpatch.htm">RTPatch</a>, the expensive commercial diffing tool!<br /><br />I'm using a Windows ported version of <a href="http://evanjones.ca/software/xdelta-win32.html">Xdelta 1.1.3</a> in a project I'm working on here, and it works great. (I realize that XDelta 1.1.3 is old, but I like how fast it is relative to the results).  Because that version is licensed under the GPL, I am including a copy of XDelta.exe with the program instead of integrating the code directly.  I'm content to continue doing this, as obviously I want to respect your licensing wishes for the software. (<a href="http://code.google.com/p/xdelta/wiki/LicensingXdelta">*</a>)</ul>Thanks! Another writes:<ul>I hope you can release a bugfix and rub off the beautymarks. xdelta-1.1.x is still used widely and a maintenance release would be appreciated.</ul>Thanks again! =)<br /><br />This is a maintenence release: <a href="http://code.google.com/p/xdelta/downloads/detail?name=xdelta-1.1.4.tar.gz">Xdelta 1.1.4</a> remains substantially unchanged since 1999.  This release fixes a bug: Compressed data from 32-bit platforms failed to decompress on 64-bit platforms. This is fixed in the decoder (it was a badly-designed "hint", now ignored), so you can now read old 32-bit patches on 64-bit platforms. Patches produced by 1.1.4 are still readable by 1.1.3 on the same platform. Still, Xdelta 1.1.x is losing its edge. <br /><br />Xdelta3 compresses faster and better, using a standardized data format&mdash;<a href="http://www.rfc-editor.org/rfc/rfc3284.txt">VCDIFF</a>, and has no dependence on gzip or bzip2. If using a standardized encoding is not particularly important for you, Xdelta3 supports secondary compression options. Xdelta3 (with the <tt>-9 <a href="http://code.google.com/p/xdelta/wiki/BetterCompression">-S djw</a></tt> flags) is comparible in terms of compression, but much faster than <a href="http://www.daemonology.net/bsdiff/">bsdiff</a>. Xdelta3 includes a Windows <tt>.exe</tt> in the official release.<br /><br />As always, I'm interested in your feedback (file a new <a href="http://code.google.com/p/xdelta/issues/entry">issue</a>). Are you compressing gigabyte files with Xdelta3? Have you used <a href="http://www.pocketsoft.com/gorilla.htm">dfc-gorilla</a> (by the makers of RTPatch)?
