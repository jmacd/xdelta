Release 3.0.3 (<a href="http://code.google.com/p/xdelta/downloads/detail?name=xdelta3-3.0.3.tar.gz&amp;can=2&amp;q=">source</a>)<br />
<br />
This release fixes issues with <a href="http://code.google.com/p/xdelta/wiki/ExternalCompression" style="background-color: white;">external compression</a> and potential buffer overflows when using the -v setting (verbose output) with very large input files.<br />
<br />
This release includes automake / autoconf / libtool support.<br />
<br />
A sample iOS application is included, demonstrating how to use xdelta3 with the iPad / iPhone.<br />
<br />
I've updated the 32-bit Windows binary <a href="http://code.google.com/p/xdelta/downloads/detail?name=xdelta3-3.0.2-x86-32.exe&amp;can=2&amp;q=">here</a>, I'll post an update when a 64-bit build is available.<br />
