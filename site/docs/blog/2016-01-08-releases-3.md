<div class="blogger-post">
Releases <a href="https://github.com/jmacd/xdelta-devel/releases/tag/v3.1.0">3.1.0</a> and <a href="https://github.com/jmacd/xdelta-devel/releases/tag/v3.0.11">3.0.11</a>&nbsp;are available.<br />
<br />
3.0.11 is a bug-fix release addressing a performance bug and several crashes in the decoder (discovered by&nbsp;<a href="http://lcamtuf.coredump.cx/afl/">afl-fuzz</a>).<br />
<br />
3.1.0 is a beta release, supports source-window buffer values (-B) greater than 2GB.<br />
<br />
The 3.1.0 release uses a 64-bit hash function, currently performs 3-5% slower and has 1-2% worse compression. This will be addressed in future releases.
