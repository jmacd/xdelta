This is a bug fix for a performance regression in 3.0.5, which I made available on November 12, 2012 without announcement.  The 3.0.5 encoder would achieve poor compression for inputs larger than the source window, due to an improper fix for <a href="http://code.google.com/p/xdelta/issues/detail?id=149">issue 149</a>.<br />
<br />
Please accept my apologies!  This has demonstrated several needed improvements in the release process I'm using, which I'll work on putting in the next release.<br />
