Xdelta-3.0s release notes:<br /><ul><li>Faster! Several optimizations to avoid unnecessary arithmetic</li><li><tt>xdelta3</tt> <tt>-1</tt> has faster/poorer compression (<tt>xdelta3</tt> <tt>-2</tt> is the former configuration)</li><li><tt>-S</tt> <tt>djw</tt> exposes secondary compression levels as <tt>-S</tt> <tt>djw1</tt> .. <tt>-S</tt> <tt>djw9</tt></li><li>Removes "source file too large for external decompression" error check</li><li>API support for transcoding other formats into VCDIFF</li></ul>Xdelta-3.0r release notes:<br /><ul><li>Fixes an encoder crash caused by <tt>-S</tt> <tt>djw</tt> (secondary compressor) on certain data, new tests for code-length overflow</li><li>Adds new <tt>recode</tt> command for re-encoding a delta with different secondary compression settings</li><li>Fixes API-specific bugs related to non-blocking calls to <tt>xd3_encode_input</tt> and <tt>xd3_decode_input</tt></li><li>Adds new <tt>examples/encoder_decoder_test.c</tt> program for the non-blocking API</li></ul>As an example of the new <tt>recode</tt> command and secondary compression options:<pre>$ ./xdelta3 -S none -s xdelta3.h xdelta3.c OUT  # 53618 bytes<br />$ ./xdelta3 recode -S djw1 OUT OUT-djw1         # 51023 bytes<br />$ ./xdelta3 recode -S djw3 OUT OUT-djw3         # 47729 bytes<br />$ ./xdelta3 recode -S djw6 OUT OUT-djw6         # 45946 bytes<br />$ ./xdelta3 recode -S djw7 OUT OUT-djw7         # 45676 bytes<br />$ ./xdelta3 recode -S djw8 OUT OUT-djw8         # 45658 bytes<br />$ ./xdelta3 recode -S djw9 OUT OUT-djw9         # 45721 bytes<br /></pre>Secondary compression remains off by default.  Passing <tt>-S</tt> <tt>djw</tt> is equivalent to <tt>-S</tt> <tt>djw6</tt>.
