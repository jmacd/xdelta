Xdelta3 has a stream-oriented <a href="http://code.google.com/p/xdelta/wiki/ProgrammingGuide">C/C++ interface</a>.  The application program can compress and decompress data streams using methods named <tt>xd3_encode_input<b>()</b></tt> and <tt>xd3_decode_input<b>()</b></tt>. With a non-blocking API, it's about as easy as programming <a href="http://www.zlib.net/manual.html#Basic%20functions">Zlib</a>.<br /><br />Read about it <a href="http://code.google.com/p/xdelta/wiki/ProgrammingGuide">here</a>.<br /><br />Thanks for your feedback (file a new <a href="http://code.google.com/p/xdelta/issues/entry">issue</a>).
