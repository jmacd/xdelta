<tt>#include &lt;windows.h&gt;</tt><br /><br />Ladies and Gents, <br />Version 3.0h runs on Windows.<br />Please head straight for the latest download of your choice:<br /><br /><a href="http://xdelta.googlecode.com/svn/trunk/xdelta3/releases/xdelta30h.tar.gz">Source</a><br /><a href="http://xdelta.googlecode.com/svn/trunk/xdelta3/releases/xdelta30h.x86-32.exe">Windows x86-32</a><br /><a href="http://xdelta.googlecode.com/svn/trunk/xdelta3/releases/xdelta30h.ppc-osx.bin">OSX PPC</a><br /><br />I thought I'd share this first and test it later, let you be the judge.<br /><br />There are not a lot of platform dependencies. The main() routine has helpful options:<ul><li><tt>/DXD3_STDIO=1</tt> builds with portable I/O routines<br /><li><tt>/DEXTERNAL_COMPRESSION=0</tt> builds without external compression, which requires POSIX system calls</ul>A call to gettimeofday() had to be replaced:<pre class=code><br />static long<br />get_millisecs_now (void)<br />{<br />#ifndef WIN32<br />  struct timeval tv;<br />  gettimeofday (& tv, NULL);<br />  return (tv.tv_sec) * 1000L + (tv.tv_usec) / 1000;<br />#else<br />  SYSTEMTIME st;<br />  FILETIME ft;<br />  __int64 *pi = (__int64*)&ft;<br />  GetLocalTime(&st);<br />  SystemTimeToFileTime(&st, &ft);<br />  return (long)((*pi) / 10000);<br />#endif<br />}<br /></pre>The remaining changes were minimal, such as the printf format string for 64bit file offsets. I haven't run a 64bit test on Windows&mdash;I was too busy posting this. :-)<br /><br />Please file issues <a href="http://code.google.com/p/xdelta/issues/entry">here</a> or send mail to &lt;josh&#x2e;macdonald&#x40;gmail&#x2e;com&gt;.<br /><br />(Thanks to <a href="http://tortoisesvn.tigris.org/">TortoiseSVN</a> for keeping us in <a href="http://xdelta.googlecode.com/svn/trunk/xdelta3/">sync</a>.)
